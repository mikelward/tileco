      Start at login on this Chromebook

      Websites tileco opens each time you log in, in this order, as app windows on the workspace you're on, without taking focus. A change takes effect at the next login. The list stays on this Chromebook.

        Unread counts

        tileco highlights a window when a site's unread count goes up in its title, like "Inbox (3)". Gmail, Chat and Calendar are here to start with, and you can add other sites. Chrome asks for access to each site you add, on this Chromebook.

          Dim

          How dark the dim makes the windows you're not in, when it's on (turn it on under Extras).

          Mouse on this Chromebook

          A longer step per wheel click than Settings offers, set from crosh (Ctrl+Alt+T), which needs chrome://flags/#gesture-properties-dbus-service enabled once. chromeOS forgets it at each reboot, so with a step here, tileco opens a page with the lines to copy at each login.
